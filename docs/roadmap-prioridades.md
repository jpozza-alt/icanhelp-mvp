# icanHelp – Roadmap de Prioridades (MVP)

**Decisão (Sequência):**
1) CRUD de Atendimentos/Tickets (com RLS e validação)
2) Dashboard funcional (cards e métricas reais vindas dos tickets)
3) Papéis de Usuário (admin/voluntário) – enforcement na API e RLS
4) Deploy automático (Vercel + Supabase Prod)
5) UX (toasts, feedbacks, melhorias de tema)

**Critérios usados:** Impacto de negócio, Complexidade técnica, Segurança/Escalabilidade.
