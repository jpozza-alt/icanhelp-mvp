# NR1 GAP MATRIX

## Objetivo
Consolidar, de forma auditavel, o que o modulo NR-1 ja cobre, o que ainda nao cobre e qual deve ser a ordem tecnica de fechamento.

## Leitura executiva
O modulo NR-1 esta forte como jornada de produto, UX e traducao da norma para linguagem leiga.
Ainda nao esta fechado como solucao documental completa e comprovada de NR-1.
O principal gap atual nao e mais a interface.
O principal gap atual e:
1. persistencia real
2. inventario formal
3. documento de criterios do GRO/PGR
4. plano de acao documentavel
5. historico/versionamento comprovado
6. exportacao e saida auditavel

## Leitura honesta do estado atual

### O que esta bom
- jornada clara
- linguagem leiga
- boa traducao da NR-1 para experiencia
- visual validado
- espinha dorsal do modulo pronta

### O que ainda impede chamar isso de modulo normativamente fechado
- migration ainda nao comprovada como aplicada no fluxo atual
- sem prova de persistencia real do diagnostico
- sem inventario final consolidado
- sem PDF ou documento formal de saida
- sem historico comprovado de longo prazo
- sem camada documental do criterio do GRO/PGR

---

## Ordem oficial de fechamento

### FASE 1 - Persistencia real
1. confirmar estrategia de tabela principal
2. aplicar migration comprovadamente
3. validar persistencia do diagnostico
4. validar persistencia de riscos
5. validar persistencia do plano de acao
6. validar persistencia das evidencias

### FASE 2 - Artefatos documentais
1. documento de criterios do GRO/PGR
2. inventario consolidado
3. plano de acao consolidado
4. relatorio executivo em PDF
5. documento tecnico exportavel

### FASE 3 - Fechamento normativo fino
1. historico/versionamento
2. terceiros/contratadas
3. remissoes para outras NR
4. regras de enquadramento e excecoes
5. revisao final de aderencia
