# DECISAO VISUAL NR-1: Ritmo, Atmosfera e Interface Circadiana

## Decisao central

- A experiencia deve ser narrativa, calma, progressiva e imersiva.
- Alto's Adventure sera usado como referencia de ritmo e atmosfera, nao como estetica literal.
- O SaaS deve continuar institucional, premium, limpo e profissional.

## O que aproveitar da referencia

- Pouca informacao por tela.
- Movimento suave.
- Foco em uma acao por vez.
- Sensacao de jornada.
- Transicoes discretas.
- Ambiente visual calmo.
- Progressao gradual.
- Reducao de ansiedade do usuario.

## O que nao fazer

- Nao transformar o SaaS em jogo.
- Nao usar estetica infantil.
- Nao usar excesso de animacao.
- Nao usar sons obrigatorios.
- Nao usar gamificacao sem proposito.
- Nao usar fundos caricatos.
- Nao prejudicar produtividade.

## Transicoes suaves

- Fade in e fade out discretos.
- Deslocamento leve.
- Duracao curta.
- Sensacao de respiracao visual.
- Respeitar `prefers-reduced-motion`.
- Nunca atrasar a operacao.

## Interface circadiana

A interface deve adaptar luz, contraste e atmosfera em camadas:

- Horario local.
- Preferencia claro/escuro do sistema.
- Escolha manual do usuario.
- Sensor de luz ambiente somente se viavel e permitido pelo navegador.

## Atmosferas

### Manha

- Off-white/nude claro.
- Azul-marinho institucional.
- Dourado discreto.
- Energia controlada.

### Tarde

- Areia claro.
- Azul institucional.
- Produtividade e foco.

### Fim de tarde

- Nude quente.
- Salmao muito sutil.
- Dourado suave.
- Acolhimento.

### Noite

- Azul-marinho profundo.
- Cards escuros suaves.
- Texto claro.
- Brilho reduzido.
- Menos cansaco visual.

## Acessibilidade

- Contraste adequado.
- Usuario pode reduzir movimento.
- Usuario pode escolher tema manualmente.
- Informacao critica nunca depende so de cor.
- Legibilidade sempre vem antes da estetica.

## Aplicacao na jornada narrativa

- Bem-vindo ao icanHelp NR-1.
- Enter/Continuar.
- Explicacao do SaaS.
- Onde vamos chegar.
- CNPJ.
- Dashboard minimo.
- Escolha do nome de destaque.
- Perguntas guiadas.

## Paleta oficial relacionada

- Azul-marinho como base principal.
- Off-white/bege claro como fundo.
- Branco quente em cards.
- Dourado suave apenas como acento premium.
- Nude como apoio visual acolhedor.
- Salmao apenas como acento emocional pontual.
- Cores funcionais sobrias para status.
- Botao primario continua azul-marinho com texto branco.
- Dourado nao deve ser botao principal.

## Fases

- Fase 1: transicoes suaves na narrativa inicial.
- Fase 2: tokens visuais por periodo do dia.
- Fase 3: respeitar preferencia claro/escuro.
- Fase 4: controle manual de atmosfera.
- Fase 5: avaliar sensor de luz ambiente.
- Fase 6: expandir para dashboard minimo e cards guiados.

## Fora de escopo

- Banco.
- RLS.
- Tenant.
- Auth.
- `.env`.
- API nova.
- Sensor real obrigatorio.
- Diagnostico clinico individual.
- Gamificacao obrigatoria.

## Definition of Done

- Narrativa com transicoes suaves.
- Enter/Continuar com ritmo natural.
- Suporte a reduced motion.
- Tema por horario ou periodo.
- Compatibilidade claro/escuro.
- Controle manual de atmosfera.
- Visual institucional e premium.
- Interface nao parece jogo.
- Legibilidade preservada.
- Dashboard minimo e cards guiados herdam a atmosfera.

## Regra explicita de acessibilidade

A acessibilidade e requisito obrigatorio da interface circadiana.

Nenhuma transicao, cor, contraste, horario, atmosfera ou animacao pode reduzir legibilidade, compreensao ou produtividade.

O usuario deve poder reduzir movimento, manter contraste adequado e escolher manualmente uma atmosfera visual confortavel.
